# Studio Daily Workflow & Time Allocation SOP

> **SHIVAMWEBDESIGNS (SWD)**  
> **Operational Schedule for High-Performance Output**  

---

## 1. Operating Philosophy
To maintain world-class engineering quality and rapid turnaround, ShivamWebDesigns strictly partitions the workday into **Deep Work Blocks** (coding, architecture, visual design) and **Communication Windows** (client correspondence, lead research, outreach).

---

## 2. Recommended Daily Time Structure

### Phase 1: Morning Triage & Planning (09:00 – 10:00)
- **Email & WhatsApp Triage:** Review incoming client inquiries, support alerts, and form submissions.
- **Sprint Board Review:** Check `PROJECT-TRACKER.csv` for milestone deadlines due today.
- **Priority Identification:** Commit to the 2 primary engineering goals for the day.

### Phase 2: Deep Work Block 1 — Core Development (10:00 – 13:00)
- **Focus:** Pure design, coding, animation, and responsive layout engineering.
- **Rules:** Close all email clients, social apps, and non-essential messaging. Zero distractions.
- **Output:** New components built, bugs patched, unit tests validated.

### Phase 3: Midday Break & Admin (13:00 – 14:00)
- Lunch, physical rest, away-from-screen recharge.

### Phase 4: Deep Work Block 2 — Staging & QA (14:00 – 17:00)
- **Focus:** Cross-browser testing (Chrome, Safari, Firefox), performance audits via Google Lighthouse, mobile layout verifications.
- **Deployments:** Push clean builds to staging preview environments.

### Phase 5: Client Communication & Outreach (17:00 – 18:30)
- **Client Dispatch:** Send weekly progress updates, milestone review links, and follow-ups.
- **Lead Research:** Spend 30 minutes executing client research using `CLIENT-RESEARCH-CHECKLIST.md`.
- **Targeted Outreach:** Dispatch 2–3 personalized messages via LinkedIn/Email per outreach SOP.

### Phase 6: Evening Wrap-up (18:30 – 19:00)
- Commit and push all code with descriptive conventional commit messages.
- Update `LEAD-TRACKER.csv` and `PAYMENT-TRACKER.csv`.
- Prepare tomorrow’s task list.
