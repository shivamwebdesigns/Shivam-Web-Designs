## 1. The 14-Day Post-Launch Warranty

Every custom web design and engineering project delivered by **ShivamWebDesigns** includes a **complimentary 14-calendar-day warranty period** beginning the date of DNS cutover.

### What is Covered Under Warranty:
- **Code Defects:** Objective layout breaks or JavaScript execution errors originating from the delivered code.
- **Cross-Browser Inconsistencies:** Visual bugs discovered on supported modern browsers (Chrome, Safari, Firefox, Edge).
- **Broken Navigation / Links:** Any internal hyperlink or broken asset path identified within the original scope.
- **Form Routing Failures:** Correction of any serverless form routing issues.

### What is Excluded from Warranty:
- Modifications, code changes, or third-party script additions introduced by the client or third parties after handover.
- Outages caused by hosting providers, registrars, or global internet disruptions.
- New feature requests, new page additions, or conceptual redesigns outside the approved SOW.

## 2. Reporting a Support Issue

To report an issue during the warranty period:
1. Email `shivamwebdesigns23@gmail.com` with subject: `[SUPPORT] [Project Name] — Bug Description`.
2. Include:
   - Specific URL / page where the issue occurs.
   - Device model, operating system, and browser version used.
   - Screenshot or screen recording showing the behavior.
3. **Response SLA:** Critical errors addressed within 12–24 business hours; minor visual tweaks within 48 business hours.

## 4. Client Self-Maintenance Best Practices
- **Image Uploads:** Always compress raster photos (JPEG/PNG) to modern `.webp` formats under 250KB before uploading to prevent slow page loads.
- **DNS Safeguards:** Never delete CNAME or A records without consulting SWD or your technical lead.
- **Account Security:** Review user permissions on GitHub and hosting consoles semi-annually.
