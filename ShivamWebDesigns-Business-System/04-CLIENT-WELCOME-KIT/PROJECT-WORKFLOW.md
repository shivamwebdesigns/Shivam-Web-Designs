# ShivamWebDesigns — Project Workflow & Milestone Guide

Every project at ShivamWebDesigns progresses through 5 structured phases to ensure transparency, predictable delivery, and exceptional craftsmanship.

---

## The 5 Project Phases

### Phase 1: Onboarding & Discovery (Week 1)
- Asset collection (logos, copy, photography) and domain access verification.
- 30-minute Sprint Kickoff Call to align on user journeys and aesthetic benchmarks.
- **Client Milestone:** All initial assets uploaded to shared drive.

### Phase 2: Design & Interactive Prototyping (Weeks 2–3)
- Custom Figma art direction, editorial typography pairing, and modular grid architecture.
- Full interactive prototype delivered for mobile and desktop viewports.
- **Client Milestone:** Formal sign-off on visual design direction before coding begins.

### Phase 3: Modern Engineering & Staging (Weeks 4–5)
- Clean Next.js 15, React 19, and TypeScript production engineering.
- Fluid responsive layout calibration, animations, and form integrations.
- Staging URL deployed on Vercel edge infrastructure for private client testing.
- **Client Milestone:** Access to live staging preview for review.

### Phase 4: Structured Review & Refinement (Week 5)
- Client consolidates feedback using the formal `REVISION-REQUEST.md` template.
- Up to two comprehensive revision rounds to fine-tune copy, imagery, and interactive details.
- Pre-launch QA across Safari, Chrome, iOS, and Android devices.
- **Client Milestone:** Final written sign-off and settlement of remaining 50% milestone invoice.

### Phase 5: Production Launch & Handover (Week 6)
- DNS cutover to live custom domain with automatic SSL certification.
- Google Search Console sitemap indexing and Open Graph social preview verification.
- Delivery of code repository, credentials package, and Handover Guide.
- Commencement of 30-day post-launch warranty.
