## 3. Scope of Work (SOW) & Deliverables

### Phase 1: Brand Discovery & Visual Architecture
- Complete technical and UX audit of existing digital assets.
- Interactive Figma art direction, wireframes, and design system creation (typography, color tokens, layout hierarchy).
- Comprehensive prototype review session and formal design approval.

### Phase 2: Frontend Engineering & Development
- Clean-architecture production build using Next.js 15, React 19, and TypeScript.
- Semantic HTML5, Tailwind CSS, and fluid 60fps animations.
- Custom interactive lead configurator / inquiry intake form with spam protection.
- Private staging deployment on Vercel edge infrastructure for review.

### Phase 3: Performance, SEO & Quality Assurance
- Cross-browser testing across Safari, Chrome, Edge, iOS, and Android viewports.
- 100/100 Core Web Vitals calibration (sub-second LCP, zero CLS, low INP).
- Full SEO metadata architecture: Canonical tags, Open Graph cards, Twitter metadata, and JSON-LD schema.

### Phase 4: Production Launch & Handover
- Zero-downtime DNS cutover and custom domain SSL configuration.
- Google Search Console sitemap submission.
- Complete source code handover, asset packaging, and 30-day post-launch warranty.
