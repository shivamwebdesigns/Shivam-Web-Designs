SHIVAMWEBDESIGNS BRAND KIT
==========================

1_Banners        HD banners (1920x1080 and wide 1920x640 for LinkedIn / X / Facebook covers)
2_Business_Card  Front + back PNG (3.5x2 in, 600 dpi) and a 2-page PDF for printing
3_3D_Card        Interactive 3D card (swipe to turn, tap links, QR). Open the HTML in a browser.
                 Online version: https://claude.ai/artifact/NTHfS5nb2gRmrqtGCv33Y7
4_Logo_and_QR    Original logo and website QR code (https://shivamwebdesigns.devs.li)

Notes
- Check the GitHub link before printing: github.com/shivamwebdesigns is an assumed address.
- Printing: ask your printer if they need bleed (usually 3 mm extra around the edge).
- On iPhone, the 3D card works best through the online link above; the saved HTML works in Chrome/Android.
