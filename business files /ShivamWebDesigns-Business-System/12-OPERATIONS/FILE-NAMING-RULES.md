# Studio File Naming, Directory & Asset Conventions

To ensure consistency, readability, and effortless collaboration, all files in the **ShivamWebDesigns** ecosystem must adhere to these standardized rules.

---

## 1. Web Source Code Conventions
- **HTML / CSS / JavaScript:** Use lowercase `kebab-case`.
  - Examples: `index.html`, `styles.css`, `script.js`, `businesscard.html`, `legal-docs.html`.
- **Component Classes:** Use BEM-inspired lowercase with single hyphens.
  - Examples: `.swd-card`, `.swd-card__header`, `.swd-card--active`.

---

## 2. Business Operating System & Documentation
- **Master Operational Documents:** Use uppercase with hyphens (`UPPERCASE-KEBAB.md`).
  - Examples: `MASTER-INDEX.md`, `BUSINESS-WORKFLOW.md`, `PRICING-GUIDELINES.md`, `DELIVERY-CHECKLIST.md`.
- **Sequential Directories:** Prefix folder numbers with two digits (`00-`, `01-`, `02-`).
  - Example: `00-START-HERE/`, `01-BRAND-IDENTITY/`, `12-OPERATIONS/`.

---

## 3. Brand Imagery & Media Assets
- **Format:** Always save raster web images as modern `.webp` or compressed `.png`.
- **Vector Icons:** Always save logos and icons as `.svg`.
- **Dimensions in Names (When Relevant):** Include width and height if an asset serves a specific responsive role.
  - Examples:
    - `github-social-preview.png` (1280×640 px)
    - `swd-logo.svg`
    - `swd-card-front.png`
    - `swd-card-back.png`

---

## 4. Client Deliverable Files & Invoices
- **Invoices:** `INV-[YEAR]-[SEQUENCE]-[CLIENT].pdf`
  - Example: `INV-2026-0001-ACME-CORP.pdf`
- **Proposals:** `PROPOSAL-[YEAR]-[CLIENT]-[VERSION].pdf`
  - Example: `PROPOSAL-2026-ZENITH-ARCH-V1.pdf`
- **Handover Archives:** `[CLIENT]-WEBSITE-SOURCE-CODE-[YEAR-MM-DD].zip`
  - Example: `ACME-WEBSITE-SOURCE-CODE-2026-11-28.zip`
